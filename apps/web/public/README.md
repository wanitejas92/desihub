# Static assets

## hero-banner.png

Drop the homepage hero artwork here as `hero-banner.png` and it is picked up
automatically — no code change needed. `HeroBannerImage` layers it over the
built-in SVG scene (`hero-illustration.tsx`), which stays as the fallback
whenever the file is absent, so the page is never broken or empty.

Recommended: roughly 16:9, at least 1600px wide, PNG or JPG.
